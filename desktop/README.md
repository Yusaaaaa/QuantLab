# QuantLab 桌面工作台 2026.10.22

采用 Tauri 2 + React + TypeScript，内置 CodeMirror Python 编辑器和净值图表。深色霓虹与浅色毛玻璃主题可切换。回测仍由原有 Python 引擎执行。

## 直接使用

打开项目 `dist/QuantLab.app`。首次启动会查找已有 QuantLab 工作目录；如未找到，在「设置」中填入项目根目录。目录内需要已有 `.venv/bin/python` 和安装完成的 QuantLab 依赖。

1. 在研究工作台选择已有配置，再从下拉菜单选择策略 `.py`。
2. 因子下拉菜单用于打开编辑；需要策略使用时，另行将其绑定到配置。策略通过已有因子接口调用它，选择文件本身不会自动改变交易逻辑。
3. 在代码框修改策略或因子，点击保存（或 Command+S）。新建策略使用项目现有 `_template.py`；新建因子仅生成待实现的空模板。
4. 设置日期、本金、股票范围、基准、本地数据文件。展开高级设置修改策略参数、仓位方式、手续费和滑点。
5. 点击验证，再运行回测。运行会先保存编辑内容、验证配置并冻结源码快照。可查看日志或取消运行。
6. 查看净值、指标、成交和完整 HTML 报告；「历史回测」可以重新打开归档。归档仍位于项目 `runs/`。

编辑器检测到文件被外部修改时会拒绝覆盖。先自行复制需要保留的草稿，再点击「重新加载」读取磁盘版本。修改参数或代码不会自动重算已有结果，请确认结果区显示的运行编号。

## 开发与构建

项目根目录先按主 README 配置 Python 环境，再在 `desktop/` 执行：

```sh
npm ci
npm run desktop
```

需要 Node.js、Rust 工具链和 macOS 开发工具。仅浏览器开发预览：

```sh
QUANTLAB_WORKSPACE=/绝对路径/QuantLab npm run dev
```

打包：

```sh
npm run bundle
```

产物在 `src-tauri/target/release/bundle/macos/QuantLab.app`。开发预览仅监听本机 127.0.0.1:1420；打包后的 App 使用原生 IPC，不依赖该服务器。

## 文件分工

- `src/`：界面、双主题、编辑器、表单和图表。
- `src-tauri/`：原生窗口、Python 子进程、任务状态和取消。
- `vite.config.ts`：仅开发模式的本机桥接。
- `../src/quantlab/desktop_bridge.py`：文件目录、带冲突检查的保存、配置校验、运行快照和结果读取。
- `../tests/test_desktop_bridge.py`：目录边界、保存冲突、快照和错误处理测试。

## 当前范围

这是连接现有本机研究环境的桌面版本，不是内置完整 Python 环境的跨机器安装包。只运行自己信任的策略代码；编辑器不是代码安全沙箱，也没有完整 IDE 的断点调试或语言服务器。数据页面列出已有本地数据，下载仍使用原项目流程。成交表最多显示前 2,000 笔，完整记录保留在运行归档中。参数修改保存于本次运行快照，不自动覆盖原 YAML 配置。取消会停止任务，但可能留下未完成目录。
