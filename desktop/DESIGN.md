# QuantLab 界面设计决策

参考已安装的 UI UX Pro Max skill，采用其 Glassmorphism 样式建议和 React 表单交互建议。检索产生的营销落地页布局不适合研究终端，未采用。

以桌面研究工作流为主：侧栏导航；左侧策略与因子代码；右侧运行配置；下方结果。日常操作无需在代码、命令行和报告文件之间切换。

- 深色：石墨背景、青色主操作、紫色辅助光晕。霓虹仅用于焦点和强调，不覆盖正文。
- 浅色：淡冷灰背景、白色半透明面板、深色正文；沿用相同组件与语义。
- 毛玻璃：局部背景模糊、半透明面板、细描边；文本区域保持对比度。
- 图标使用 Lucide SVG。代码使用等宽字体，说明采用系统中文字体，不依赖在线字体。
- 键盘焦点可见，弹窗支持 Escape 与焦点约束，动画尊重 reduced-motion。
- 表单有可见标签；保存、验证、运行、失败均提供反馈。运行时禁用会改变输入的编辑操作。
- 图表区标识真实运行编号；历史结果与当前尚未运行的配置明确区分。

验证覆盖原生 macOS 窗口中的深浅主题、代码和参数布局、真实净值结果与完整报告。桌面窗口最小尺寸为 1000 × 720；该版本不以手机操作为目标。
