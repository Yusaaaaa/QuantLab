# GitHub export policy — 2026.10.22

This release contains the application, desktop source, current simple strategies and factor, configurations, tests, documentation and bilingual manuals. The owner explicitly authorized publishing these implementations on 2026-10-22.

Excluded: independent `researchProject/` studies and their frozen reference code/data/results; `run/` and `runs/` results; real market datasets; environment files; credentials; virtual environments, caches and built applications.

The pre-existing GitHub repository history is retained. Releases are prepared from an explicit inclusion list in a separate checkout, rather than pushing the unrelated original working repository history. Existing historical configuration paths require locally supplied data. Use generated synthetic sample data for a clean-clone smoke test.

See PROJECT_SCOPE.md and AUDIT_2026.10.22.md. This replaces the initial export's exclusion of all strategies/factors; no repository visibility change is part of this release.
